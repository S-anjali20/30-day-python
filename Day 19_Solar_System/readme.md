# 🌌 Day 19 — AstroView: Interactive Solar System

An interactive solar system simulation built with Python and Pygame as part of my **30 Days, 30 Python Projects Challenge**.

**AstroView** allows users to explore the eight planets of our solar system through animated orbital movements, interactive planet selection, and an informative planet profile panel.

---

## ✨ Features

- 🪐 **Animated Solar System:** Watch all eight planets revolve around the Sun in real time.
- 🖱️ **Interactive Planet Selection:** Click directly on any planet or use keyboard shortcuts to inspect it.
- 📊 **Planet Information Panel:** View each planet's distance from the Sun, diameter, day length, orbital period, and an interesting fact.
- ⚡ **Adjustable Simulation Speed:** Dynamically speed up or slow down planetary revolution rates.
- ⏸️ **Pause & Resume:** Pause the orbital animation anytime to inspect positions.
- ⭕ **Orbital Path Visibility:** Toggle orbital guide lines on or off.
- 🏷️ **Planet Labels:** Toggle planet names on or off for a cleaner view.
- 🌌 **Starry Background:** procedural starry space backdrop.
- ⌨️ **Convenient Keyboard Controls:** Full shortcut controls for seamless navigation.
- 🎨 **No External Assets Required:** All visuals and graphics are rendered dynamically using Pygame.

---

## 🪐 Planets Included

The simulation includes all eight planets of our solar system:

1. **Mercury** 
2. **Venus** 
3. **Earth** 
4. **Mars** 
5. **Jupiter** 
6. **Saturn** 
7. **Uranus** 
8. **Neptune** 

*Each planet features distinct colors, scaled orbital radii, customized speeds, and an interactive factual profile.*

## 🛠️ Technologies Used

| Technology / Library | Purpose |
| :--- | :--- |
| **Python** | Core programming language |
| **`pygame`** | Game loop rendering, shape drawing, animation, and event handling |
| **`math`** | Trigonometry (`sin`, `cos`) for computing smooth circular and elliptical orbits |
| **`random`** | Procedural generation of space backdrop starfields |
| **`sys`** | Application lifecycle and clean exit handling |
