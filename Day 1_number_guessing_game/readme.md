### 🐍 Day 1/30 — Number Guessing Game 🎯

For Day 1, I built an interactive **Number Guessing Game** with a colored terminal interface.

**Key Features:**
* 🎚️ 3 difficulty levels
* 🔥 Hot/cold distance-based hints
* ⬆️ Higher/lower directional hints
* ❤️ Limited attempts
* 🏆 Score tracking system
* 📊 End-of-game statistics
* 🔄 Play-again functionality
* 🎨 Colored terminal interface using `colorama`
* 🛡️ Robust input validation

**What I Learned Today:**
* Using functions to properly structure a Python program
* Handling invalid user input safely with `try/except` blocks
* Working with random number generation using the `random` module
* Using `abs()` to calculate absolute distance between values
* Breaking a larger program into smaller, single-purpose functions

> **Key Takeaway:** Even a simple project can become much more interesting when you keep improving it instead of stopping at the first working version.
