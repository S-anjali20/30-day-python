# 📚 Day 8 — AI Study Assistant

An AI-powered study assistant built with Python, OpenAI API, and Typer.

This project is part of my **30 Days – 30 Python Projects** challenge.

For this project, I moved further into AI development by building an interactive study assistant that can explain topics, generate exam-friendly notes, and create quizzes using an AI model.

---

## 🚀 Features

- 📖 Explain any study topic
- 📝 Generate exam-friendly notes
- ❓ Generate quiz questions
- 🤖 AI-powered responses
- 💻 Interactive command-line interface
- ⚡ Typer-based CLI
- 🔐 Secure API key management using `.env`
- ⚠️ Error handling for API failures

---
