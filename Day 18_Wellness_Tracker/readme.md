# 🌱 Day 18 — HabitBloom: Habit & Wellness Tracker

A desktop habit-tracking application built with Python and CustomTkinter as part of my 30 Days, 30 Python Projects Challenge.

**HabitBloom** helps users build consistent routines by tracking daily habits, monitoring streaks, visualizing weekly progress with embedded charts, and exporting personal activity summaries to CSV format.

---

## ✨ Features

- 📝 **Custom Habits:** Create, edit, and delete habits with personalized names and categories.
- ✅ **Daily Check-ins:** Mark habits as completed for any selected date.
- 📅 **Date Navigation:** Easily move between dates to review or update historical check-ins.
- 📊 **Progress Dashboard:** View daily completion percentages, active habit counts, and weekly check-in totals.
- 🔥 **Streak Tracking:** Automatically calculate current and longest consecutive-day streaks for each habit.
- 📈 **Weekly Charts:** Visualize completed habits over the last 7 days using embedded Matplotlib graphs.
- 💡 **Habit Insights:** Review total check-ins and detailed streak statistics for individual habits.
- 📄 **CSV Reports:** Export habit summaries and individual check-in records for any custom date range.
- 💾 **Persistent Storage:** Safely store habits and check-in history in a local SQLite database.
- 🌙 **Modern Interface:** Clean, dark-themed desktop dashboard built with CustomTkinter.

---

## 🛠️ Technologies Used

| Technology / Library | Purpose |
| :--- | :--- |
| **Python** | Core programming language |
| **`customtkinter`** | Modern desktop graphical user interface (GUI) framework |
| **`sqlite3`** | Relational database for persistent storage of habits and check-in records |
| **`matplotlib`** | Plotting and rendering weekly progress visualization charts |
| **`datetime`** | Date manipulation, range filtering, and consecutive streak calculations |
| **`csv`** | Exporting structured activity logs and habit reports |
| **`tkinter`** | GUI state management (`BooleanVar`) and native file save dialogs |
