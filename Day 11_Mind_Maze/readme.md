# 🧠 Mind Maze — Interactive Puzzle Game

This project is **Day 11** of my **30 Days, 30 Python Projects Challenge**.

An interactive puzzle game built with Python and Pygame that challenges players to use logical reasoning, pattern recognition, and problem-solving skills through engaging puzzles in a dark-themed gaming interface.


---

## 🎮 Features

- 🔐 **Secret Code Challenge:** Crack a hidden code consisting of four unique digits.
- 🧩 **Logic Puzzles:** Solve sequence-based puzzles using logical reasoning.
- 🎚️ **Multiple Difficulty Levels:** Choose a challenge that matches your skill level.
- 💡 **Hints System:** Get helpful clues when you get stuck.
- 🏆 **Score Tracking:** Earn points by solving puzzles.
- 🔥 **Streak System:** Build consecutive wins to improve your performance.
- 📊 **Attempt Tracking:** Monitor your progress as you solve each challenge.
- ⌨️ **Keyboard Controls:** Interact with the game using intuitive keyboard input.
- 🌙 **Dark-Themed Interface:** Enjoy a clean, game-inspired visual experience.

---

| Technology / Library | Purpose |
