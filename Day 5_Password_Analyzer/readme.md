# 🔐 Day 5 — Password Strength Analyzer

A Python-based Password Strength Analyzer that evaluates a password based on multiple security criteria and provides a strength score along with suggestions for improvement.

This project is part of my **30 Days – 30 Python Projects** challenge.

---

## 🚀 Features

- 🔐 Analyze password strength
- 📏 Check password length
- 🔠 Check for uppercase letters
- 🔡 Check for lowercase letters
- 🔢 Check for numbers
- 🔣 Check for special characters
- 🟢 Display password strength
- 💡 Provide suggestions to improve weak passwords
- 🔄 Analyze multiple passwords in one session

---

## 📋 Password Strength Criteria

The program evaluates a password using the following criteria:

- ✓ At least 8 characters
- ✓ At least 12 characters for extra strength
- ✓ At least one uppercase letter `(A-Z)`
- ✓ At least one lowercase letter `(a-z)`
- ✓ At least one number `(0-9)`
- ✓ At least one special character

---

## 📊 Strength Levels

The password receives a score out of 6.

| Score | Strength |
|------:|----------|
| 0–2 | 🔴 Very Weak |
| 3 | 🟠 Weak |
| 4 | 🟡 Medium |
| 5 | 🟢 Strong |
| 6 | 💪 Very Strong |
