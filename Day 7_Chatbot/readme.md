# 🤖 Day 7 — AI Chatbot with Conversation Memory

An AI-powered chatbot built with Python and the OpenAI API.

This is Day 7 of my **30 Days – 30 Python Projects** challenge.

In Version 2, I upgraded the basic chatbot by adding **conversation memory**, allowing the AI to understand previous messages and maintain context throughout the conversation.

---

## 🚀 Features

- 🤖 AI-powered conversations
- 💬 Interactive command-line chatbot
- 🧠 Conversation memory
- 🔄 Maintains context between messages
- 🗑️ Clear conversation memory
- 🚪 Exit command
- ⚠️ Error handling
- 🔐 API key stored securely using environment variables

---

## 🧠 How It Works

The chatbot maintains a conversation history containing both user and AI messages.

```text
User Message
     ↓
Conversation History
     ↓
OpenAI API
     ↓
AI Response
     ↓
Add Response to History
     ↓
Next User Message
```
