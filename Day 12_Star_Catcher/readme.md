# ⭐ Day 12 — Star Catcher

A fun and interactive 2D arcade game built with Python and Pygame as part of my **30 Days, 30 Python Projects Challenge**! 

Catch falling stars to earn points, avoid bombs, and challenge yourself to achieve the highest score! 🌟

---

## 🎮 About the Project

**Star Catcher** is a fast-paced 2D arcade game where the player controls a basket at the bottom of the screen to catch falling stars. Every star caught increases your score, but catching a bomb costs a life! As your score increases, the falling speed and difficulty ramp up, making every round exciting.

---

## ✨ Features

- ⭐ **Catch Stars:** Collect falling stars to earn points.
- 💣 **Avoid Bombs:** Dodge incoming bombs to protect your lives.
- 🏆 **High Score Tracking:** Save and track your highest score locally using JSON.
- ❤️ **Health System:** Start with 3 lives per game round.
- 📈 **Dynamic Difficulty:** Game speed increases as your score grows.
- ⏸️ **Pause & Resume:** Pause the game mid-play at any time.
- 🔄 **Quick Restart:** Restart instantly after a game over screen.
- 🎮 **Responsive Controls:** Smooth left/right movement using keyboard inputs.

---

## 🛠️ Technologies Used

| Technology / Library | Purpose |
| :--- | :--- |
| **Python** | Primary programming language |
| **Pygame** | Game loop, rendering graphics, sprite collisions, and keyboard input |
| **JSON** | Persistent storage for saving and loading high scores (`highscore.json`) |
