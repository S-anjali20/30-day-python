# ⭐ Day 15 — FocusFlow Productivity Timer

A modern and interactive desktop productivity application built with Python and CustomTkinter as part of my **30 Days, 30 Python Projects Challenge**!

Stay focused, organize your tasks, and track your productivity with FocusFlow — an all-in-one dashboard designed to help you manage your time using the Pomodoro technique. 🍅

---

## 🎯 About the Project

**FocusFlow** is a desktop productivity application that combines a customizable Pomodoro timer, task manager, session history, and daily progress dashboard in one interface.

Users can switch between focus sessions and breaks, manage their daily tasks, and track their productivity over time. All tasks and completed focus sessions are stored locally using SQLite, ensuring that progress remains available even after restarting the application.

---

## ✨ Features

- 🍅 **Pomodoro Timer:** Switch between focus, short-break, and long-break modes.
- ⚙️ **Customizable Durations:** Configure focus time, break lengths, and daily session goals.
- ⏯️ **Timer Controls:** Start, pause, resume, reset, or skip the current timer.
- 📝 **Task Manager:** Add tasks, mark them as complete, and select the task you're focusing on.
- 📊 **Daily Dashboard:** Track focused minutes, completed focus sessions, and completed tasks.
- 💾 **Session Tracking:** Save completed focus sessions in a local SQLite database.

---

## 🛠️ Technologies Used

| **Technology / Library** | **Purpose** |
| ------------------------ | ----------- |
| **Python** | Primary programming language |
| **CustomTkinter** | Modern desktop GUI and interface components |
| **Tkinter** | GUI event handling and dialog boxes |
| **SQLite (`sqlite3`)** | Local database for tasks and completed focus sessions |
| **Time-based callbacks** | Timer countdowns and automatic mode transitions |

---


## 💾 Data and Privacy

- 🗃️ **Local Database:** All tasks and session history are stored in `focusflow.db`.
- 🔐 **No Account Required:** The application does not require registration or login.
- 🌐 **Offline Friendly:** No network connection is required for the core features.
- 🔄 **Persistent History:** Your tasks and session records remain available after restarting the app.
- ⚠️ **Backup:** Keep a copy of `focusflow.db` if you want to preserve your local productivity history when moving to another computer.
