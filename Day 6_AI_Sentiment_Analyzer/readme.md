# 🤖 Day 6 — AI Sentiment Analyzer

An AI-powered Sentiment Analyzer built with Python and Hugging Face Transformers.

The application analyzes user-provided text and predicts whether the sentiment is **Positive, Neutral, or Negative**, along with a confidence score.

This project is part of my **30 Days – 30 Python Projects** challenge.

---

## 🚀 Features

- 🤖 AI-powered sentiment analysis
- 😊 Positive sentiment detection
- 😐 Neutral sentiment detection
- 😞 Negative sentiment detection
- 📊 Confidence score for predictions
- 📝 Interactive text input
- 🔄 Analyze multiple texts in one session
- ⚠️ Empty input handling
- 🧠 Uses a pre-trained Transformer-based NLP model
- 💻 Simple command-line interface

---

## 🧠 How It Works

The application uses a pre-trained Natural Language Processing (NLP) model from Hugging Face.

The basic workflow is:

```text
User enters text
       ↓
Text is sent to AI model
       ↓
Transformer model analyzes the text
       ↓
Sentiment is predicted
       ↓
Positive / Neutral / Negative
       ↓
Confidence score is displayed
```
